# DM Weather Framework 
In this project, we aim to develop an end to end weather framework that uses climate data (temperature, pressure, precipitation, wind speed, etc.) to forecast the 2-meter temperature class. By applying data mining and machine learning techniques, we will also explore patterns and relationships between environmental variables at different regions.
